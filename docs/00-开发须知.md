```
项目仓库/
├─ docs/                  # 文档目录，存放所有开发相关文档
│  ├─ 00-开发须知.md       # 开发须知文档
│  ├─ 01-需求文档/        # 需求相关文档

│  └─ 03-部署手册/        # 系统部署相关文档
│     └─ 逸享荟部署步骤.md # 部署步骤说明
├─ lankong-admin/           # 后端代码目录（基于 RuoYi 框架）
│  ├─ src/                # 后端源码
│  ├─ resources/          # 配置文件（如 application.yml）
│  └─ pom.xml             # Maven 项目配置文件
├─ ruoyi-ui/              # 前端代码目录（基于 RuoYi-Vue 框架）
│  ├─ src/                # 前端源码
│  ├─ public/             # 静态资源
│  └─ package.json        # 前端依赖配置文件
```

### 说明
1. **docs/**：文档目录，按需求、设计、部署分类，便于查阅和维护。
2. **lankong-admin/**：后端代码目录，基于 RuoYi 框架开发，包含业务逻辑、数据访问层等。
3. **ruoyi-ui/**：前端代码目录，基于 RuoYi-Vue 框架开发，包含页面组件、接口调用等。

### 标准项目信息
一、项目基本信息
- 项目类型：Spring Boot 2.7.x 后端单体应用（电商订单管理系统）

- 技术栈：JDK 11、Spring Boot 2.7.5、MyBatis-Plus 3.5.3、MySQL 8.0、Redis 6.x、RabbitMQ 3.9.x、Lombok、Hutool

六、业务背景
- 核心用途：电商平台的订单管理系统，支持用户下单、查询订单、取消订单，对接支付系统和库存系统；
- 业务场景：用户在APP选择商品后提交订单，系统扣减库存，生成待支付订单，用户支付后更新订单状态，超时未支付自动取消；
- 并发量：日均订单量1万+，峰值500QPS。
