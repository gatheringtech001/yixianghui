# 项目结构

```
项目仓库/
├─ docs/                  # 文档目录，存放所有开发相关文档
│  ├─ 00-开发须知.md       # 开发须知文档
│  ├─ 01-需求文档/        # 需求相关文档
│  │  └─ 逸享荟功能清单.md # 功能清单文档
│  ├─ 02-设计文档/        # 系统设计相关文档
│  │  └─ 逸享荟详细设计.md # 详细设计文档
│  └─ 03-部署手册/        # 系统部署相关文档
│     └─ 逸享荟部署步骤.md # 部署步骤说明
├─ ruoyi-admin/           # 后端代码目录（基于 RuoYi 框架）
│  ├─ src/                # 后端源码
│  ├─ resources/          # 配置文件（如 application.yml）
│  └─ pom.xml             # Maven 项目配置文件
├─ ruoyi-ui/              # 前端代码目录（基于 RuoYi-Vue 框架）
│  ├─ src/                # 前端源码
│  ├─ public/             # 静态资源
│  └─ package.json        # 前端依赖配置文件
```

### 说明
1. **docs/**：文档目录，按需求、设计、部署分类，便于查阅和维护。
2. **ruoyi-admin/**：后端代码目录，基于 RuoYi 框架开发，包含业务逻辑、数据访问层等。
3. **ruoyi-ui/**：前端代码目录，基于 RuoYi-Vue 框架开发，包含页面组件、接口调用等。
