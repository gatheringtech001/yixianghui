## 二、系统功能概览

本系统基于 **RuoYi-Vue 3.8.x** 扩展，面向 **PC 后台管理** 与 **微信小程序** 双端，核心业务包括：

| 模块 | 功能说明 | 主要使用者 |
| --- | --- | --- |
| 认证登录 | 微信小程序登录、第三方授权、JWT Token 签发 | 小程序用户、管理员 |
| 首页/公共 | 分站定位、商品/活动/广告/图文/会员卡浏览、SKU 查询 | 小程序访客 |
| 用户中心 | 个人信息、地址、收藏、购物车、优惠券、签到金币 | 小程序用户 |
| 商品订单 | 下单、微信支付、取消、退款/售后 | 小程序用户、管理员 |
| 活动预约 | 活动分类/活动列表、预约报名与取消 | 小程序用户、管理员 |
| 康养顾问 | 顾问申请、上下级关系、客户列表、收入明细 | 顾问、管理员 |
| 客户管理 | 客户资料 CRUD、导入导出、顾问分配 | 管理员、顾问 |
| 商城后台 | 商品/SKU/分类/优惠券/供应商等全量配置 | 平台管理员 |
| 内容与运营 | 广告位、图文、单页、行政区域、商城配置 | 平台管理员 |
| 财务记录 | 支付/退款/充值/提现/金币/积分/钱包流水 | 管理员 |

## 三、技术架构

```
微信小程序 / PC 后台(Vue)
        │
        ▼
   Nginx（可选）
        │
        ▼
lankong-admin (Spring Boot, port 8080)
  context-path: /api
  ├── controller/app/*     业务接口（本文档范围）
  ├── controller/system/*  RuoYi 系统接口（登录、用户、角色等）
  └── Swagger + Spring Security + JWT
        │
        ▼
   MySQL 8.0 + Redis
```

**后端控制器分包：**

- `controller/app/AppIndexController`、`AppUserController` — 小程序端（前缀 `/mnp/*`）
- `controller/app/App*Controller`（其余 42 个）— 后台管理（前缀 `/system/*`）
- `controller/system/SysAuthController` — 登录授权（前缀 `/system/auth`）

## 四、接口通用规范

### 4.1 基础 URL

| 环境 | Base URL |
| --- | --- |
| 本地开发 | `http://localhost:8080/api` |
| 生产 | `https://{域名}/api` |

**完整路径 = Base URL + 控制器 `@RequestMapping` + 方法路径**

示例：查询商品列表 → `GET /api/mnp/index/get_goods_list`

### 4.2 认证方式

| 场景 | Header | 说明 |
| --- | --- | --- |
| 已登录接口 | `Authorization: Bearer {token}` | JWT，登录成功后返回 |
| 匿名接口 | 无 | 标注 `@Anonymous`，如首页商品列表 |
| 后台 RBAC | `Authorization` + 权限标识 | `@PreAuthorize("@ss.hasPermi('system:xxx:yyy')")` |

**小程序登录：**

```
GET /api/system/auth/wxmnp/login?code={wxLoginCode}&inviterId={可选邀请人ID}
```

返回 `AjaxResult`，`data.token` 为后续请求使用的 JWT。

### 4.3 统一响应结构

**分页列表（TableDataInfo）：**

```json
{
  "total": 100,
  "rows": [],
  "code": 200,
  "msg": "查询成功"
}
```

**普通操作（AjaxResult）：**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

| code | 含义 |
| --- | --- |
| 200 | 成功 |
| 401 | 未登录或 Token 失效 |
| 403 | 无权限 |
| 500 | 服务端错误 |

### 4.4 分页与筛选

列表接口通用 Query 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| pageNum | int | 页码，默认 1 |
| pageSize | int | 每页条数，默认 10 |
| orderByColumn | string | 排序字段（可选） |
| isAsc | string | asc / desc（可选） |
| 实体字段 | varies | 与 Domain 对象字段同名，作筛选条件 |

### 4.5 后台标准 CRUD 模式

绝大多数 `/system/app_*` 控制器遵循相同 6 接口模式：

| 方法 | 路径 | 说明 | 典型权限后缀 |
| --- | --- | --- | --- |
| GET | `/list` | 分页列表 | `:list` |
| POST | `/export` | 导出 Excel | `:export` |
| GET | `/{id}` | 详情 | `:query` |
| POST | `/` | 新增 | `:add` |
| PUT | `/` | 修改 | `:edit` |
| DELETE | `/{ids}` | 批量删除 | `:remove` |

权限完整格式：`system:{模块标识}:{操作}`，例如 `system:app_goods:list`。

## 八、核心业务流程

### 8.1 小程序商品下单

```
1. GET  /mnp/index/get_goods_info/{goodsId}     查看商品
2. ALL  /mnp/index/goods_sku_data?goodsId=      选择规格
3. GET  /mnp/app_user/get_coupon_enable_list    选优惠券（可选）
4. POST /mnp/app_user/add_goods_order           创建订单
5. POST /mnp/app_user/pay_goods_order          发起微信支付
6. ALL  /mnp/app_user/wxpay_notify              微信回调更新状态
```

### 8.2 小程序登录

```
1. wx.login() 获取 code
2. GET /system/auth/wxmnp/login?code=xxx
3. 保存 data.token，后续请求带 Authorization Header
4. GET /mnp/app_user/data 获取用户信息
```

### 8.3 顾问查看客户

```
2. GET /mnp/app_user/consultant/customer_list   客户列表
3. GET /mnp/app_user/get_goods_order_list       客户订单（按权限过滤）
```
